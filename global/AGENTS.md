# CLI tools

Available: `rg` for text search; `fd` for finding files; `ast-grep` for structural code search/rewrites; `jq` for JSON; `yq` (Mike Farah) for YAML/config queries and edits; `hyperfine` for repeated command benchmarks (distinguish warm/cold caches); `gh` for GitHub; `uv` for Python environments/tools. Use `fzf --filter` for noninteractive filtering. Prefer project-owned commands for checks and review diffs after automated rewrites.

# Browser

Use T3 Preview as the primary browser: start with `preview_status`, then `preview_open` if needed. Make every reasonable effort to complete browser work in T3 Preview before falling back. A missing tab or `available: false` from `preview_status` is not a reason to switch; try `preview_open`. For recoverable failures, inspect the error and current tab state, refresh stale snapshot locators, and try a different supported Preview approach where useful. Do not switch merely because the same step failed twice; first exhaust meaningful recovery options without repeating identical failing calls indefinitely. Fall back to Chrome only when Preview tools are unavailable, `preview_open` reports unsupported, or concrete failures show that Preview cannot complete the task after reasonable recovery attempts. Honor an explicit browser preference. Briefly report the error and exhausted recovery attempts before switching, continue at the same URL, and preserve user tabs and data. If Chrome is also uncontrollable, try Zen when available; otherwise report the blocker and continue independent work.
