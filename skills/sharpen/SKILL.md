description: "Deepen a task and rewrite its prompt without executing it. Use for $sharpen."
---

Make the task deeper without expanding its scope. Before rewriting it:

1. Explain what a top professional would add to the approach.
2. Identify the raw source material they would start from.
3. Name the specific methods and tools they would use.
4. Identify an independent check that would establish the result is right.

Then return a rewritten prompt that incorporates those improvements. Preserve explicit user constraints and leave choices that belong to the user open. Do not execute the rewritten task.
