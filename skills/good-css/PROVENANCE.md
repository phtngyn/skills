# Source and ownership

`SKILL.md` and `references/EMIL_INTEGRATION.md` are our personal Codex wrapper and integration guidance around [Vojta Holik's Good CSS](https://github.com/vojtaholik/good-css), reviewed at [`e6174b7a720f58c8e7e997eec559ab8bd6fc44df`](https://github.com/vojtaholik/good-css/tree/e6174b7a720f58c8e7e997eec559ab8bd6fc44df). The upstream entry point and its eight reference categories remain unchanged in `repos/good-css/skills/good-css`.

The checkout and referenced resources are runtime dependencies. Source links resolve from this wrapper's real directory; no upstream skill directory is nested inside it. The retained upstream MIT license identifies the source's terms. The wrapper does not imply upstream authorship or endorsement.

Good CSS already delegates motion design and tuning to Emil. Our adjustments route that delegation through the personal Emil wrapper, target source reads to matching technique entries, preserve project conventions and scope, and resolve overlaps involving inherited animation variables, animated layout properties, and mobile root scrolling. Compatibility checks distinguish optional visual enhancements from required interactions.

The upstream `PRACTICES.md` contains explanations and credits; its category references are generated by upstream tooling. [good-css.com](https://good-css.com/) supplies live specimens and additional context. The site is supplementary evidence and may differ from the adopted source revision.

[UPSTREAM.md](../../UPSTREAM.md) records the source pin and fetched revision. Review and adopt changes there without rewriting or generating files in the reference checkout during ordinary application work.
