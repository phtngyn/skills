## Task and Codex adaptations

For a naming question, inspect the upstream headings and read only the matching effect entries and their distinctions. Use those entries to identify the effect and the properties that distinguish it. Do not load implementation or delegation guidance for a naming answer. Describe only what the supplied reference supports, and state uncertainty when a still image cannot establish timing or motion. Do not build an animation merely to answer a naming question. If the user requests implementation, carry the identified effect into [design-animate](../design-animate/SKILL.md).
