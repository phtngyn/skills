# Example prompts

- `$poteto-mode fix duplicate rows after a retry. Reproduce the duplicate, fix its cause, and verify retries preserve one row.`
- `$architect with checkpoint redesign this importer around its callers and failure contract. Show the proposed types before implementation.`
- `$how explain how this subsystem owns its resources and what happens during shutdown.`
- `$why investigate why this timeout exists. Separate recorded reasons from inference.`
- `$interrogate review this branch against the accepted requirements. Report issues without editing.`
- `$poteto-mode plan only: migrate these callers and remove the obsolete API. Name a verification gate for each phase.`
- `$poteto-mode check on PR 123. Make one status pass and report remaining blockers.`
- `$figure-it-out migrate the collection to the agreed layout. Keep a decision log and verify the installed result.`
