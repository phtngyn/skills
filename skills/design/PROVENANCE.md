# Source and ownership

`design` is the coordinator for an independent family of local Codex skills. Its thirteen `design-*` specialists have their own entry points and explicit invocation policies. They reuse this family's [source rules](references/SOURCES.md) and load the [implementation workflow](references/WORKFLOW.md), [delegation notes](references/DELEGATION.md), and [CSS integration rules](references/CSS_INTEGRATION.md) only when the task needs them. The coordinator routes to the specialists; each specialist can also be invoked directly without loading the coordinator.

The UI craft comes from [Emil Kowalski's skills](/Users/phtngyn/Developer/skills/repos/emil), unchanged in `repos/emil`. CSS implementation uses Vojta Holik's [Good CSS](/Users/phtngyn/Developer/skills/repos/good-css), unchanged in `repos/good-css`. Local adapters read the selected original workflow or matching lookup sections and relevant resources rather than bundling shortened versions of the detailed guidance. Loaded instructions and source evidence are reused within the active context. The [source map](references/SOURCE_MAP.md) records the local names for upstream specialists.

The local family adds task routing, collaboration and verification rules, Codex tool adaptation, project styling preferences, and explicit handoffs between read-only and implementation tasks. It has no dependency on another skill family. The source checkouts and their resources remain runtime dependencies, outside the installed family, so excluded source skills are not discovered as independent installed entries.

The based-on commits in [UPSTREAM.md](../../UPSTREAM.md) identify the adopted Emil and Good CSS revisions. Keep each source at its recorded revision until an update is deliberately adopted. Fetching does not adopt an update. Review changed guidance and local adapters together before advancing a clean checkout and its based-on record. Retain the upstream [MIT license](LICENSE) and Good CSS [MIT license](licenses/GOOD_CSS_LICENSE). The local adaptations do not imply either upstream author authored or endorsed them.

Excluded by user preference: `ask-sonner`, `pick-ui-library`, `write-swift`, and `animate-expo`. They remain unchanged in the upstream checkout for source integrity but are not installed, routed to, or loaded by this family.
