# Design source rules

The adapters use the unchanged Emil and Good CSS checkouts. Keep each selected checkout at its based-on commit in [UPSTREAM.md](../../../UPSTREAM.md). Report missing or mismatched sources instead of substituting another installed skill or changing the pin. Resolve resources from the owning source directory and installed links from their real paths.

Local adapters override conflicting upstream instructions. Preserve complete technique conditions and component-specific exceptions. Excluded sources: `ask-sonner`, `pick-ui-library`, `write-swift`, and `animate-expo`. Reuse project primitives for incidental component choices.

## Select references

Reuse instructions already in context. For naming or a narrow question, inspect source headings and read the matching sections. For construction or structured audits and reviews, read the selected workflow and its constraints, then the applicable recipes.

Use [Design workflow](WORKFLOW.md) for implementation, exploration, or substantial planning, [delegation notes](DELEGATION.md) when assigning work, and the [source map](SOURCE_MAP.md) when following an upstream handoff. These are conditional references.
